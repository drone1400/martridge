--- V0.10.0.0 ---
- changes/fixes to how paths get saved in config files
- can now add paths for dmod/game/editor manually by pasting them in
- configuration data and application state (window size/position/etc) now get saved in different files
- finally fixed DMOD launching config defaults for TrueColor, Sound and Joystick
- DMOD launcher now supports "steam://rungameid/<id>//<args>/" (even though it doesn't really work :/ uuuh...)
- DMOD launcher now supports running games through Wine on Linux/Mac
- added an extension configuration file for game/editor exe paths to allow running them through Steam or through Wine
- if you add a windows game exe like from DinkHD as a non Steam game on the Steam Deck, Martridge can now automatically detect this by reading Steam's shortcuts.vdf file and automatically tries to configure the game to run through Wine/Proton (you need to launch the game at least once through Steam after configuring Proton for this to work) 
- various UI tweaks to make Martridge look better on the Steam Deck
- UI changes/tweaks in Settings
- UI changes/tweaks in Online DMOD browser (ex, you can now see what page is currently being downloaded)
- fixed some issues with DMOD selection in Local and Online DMOD browser UI
- martridge now automatically refreshes Online DMOD list and selected Online DMOD data when needed
- note: by default, Online DMOD list is refreshed every 5 days, might make this interval shorter before release...
- fixed issue with reading the DMOD.DIZ file with the wrong encoding
- various internal code changes/refactoring/cleanup stuff
